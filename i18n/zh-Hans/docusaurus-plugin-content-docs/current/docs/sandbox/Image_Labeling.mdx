图像注释工具用于标注机器学习训练数据、查看医学图像，以及标记照片以提供反馈。Konva.js 内置了 Canvas 拖放、图形绘制和事件处理功能，因此可以用它构建此类工具。

此示例展示使用 React 和 react-konva 构建的图像标注系统。阅读[完整案例研究](https://lavrton.com/case-study-image-labeling-for-machine-learning/)，了解开发过程。

此小组件使用 `React`、`Konva` 和 `react-konva` 库构建。

此类应用不要求使用 `React`。此处选择 React，是因为使用该系统的主应用由 `React` 构建。
