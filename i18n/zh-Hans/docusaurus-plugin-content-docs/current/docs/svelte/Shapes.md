所有 `svelte-konva` 组件都对应同名的 `Konva` 组件。除非另有说明，`Konva` 对象的所有可用参数都可以作为对应 `svelte-konva` 组件的有效 props。

核心图形包括：Rect、Circle、Ellipse、Line、Image、Text、TextPath、Star、Label、SVG Path、RegularPolygon。还可以创建自定义图形。

有关 Konva 的详细信息，请阅读 [Konva 概览](/docs/overview.html)。
